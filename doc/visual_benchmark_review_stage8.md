## 当前差距判断

### 不是完成画面

当前阶段 8A 演示是我做的“可操作功能演示”，不是最终设计完成画面。它解决了：

- 主角能移动。
- 木牌能打开、兑换、赠送图纸。
- 森林/河岸/河水能采集。
- 建设节点会切换场景对象。
- 游戏机能进入小游戏。
- 小游戏收贴纸后能回到主世界并更新贴纸墙。

但它还没有达到你给的参考图水平，主要差距：

- 森林像“树的数组”，不是生活化森林边缘。
- 河流像“蓝色长条”，缺少河岸高度、岸线弧度、水面高光和可接近浅滩。
- 主角代理体已有黑发/紫黑/灵鱼方向，但还不够像一个有角色记忆点的形象。
- 家园节点可读，但木屋、木牌、贴纸墙、建设物的质感层级不足。
- 镜头和构图还没有像参考图那样把主角、家、桥、河和生活入口组织成一个截图中心。

## 对标拆解

### 动森参考方法

可学习：

- 角色轮廓大而清楚，头身比例夸张，表情和服装先于细节被识别。
- 家/店/桥/河在同一张画面里承担空间锚点，玩家不需要看地图也知道去哪。
- 树木数量不多，但每棵树体积大、冠层圆、间距宽，形成“森林边缘”而不是树墙。
- 河岸边界干净，桥是自然跨越点，水面不需要复杂但要有明亮边缘。
- 生活工具入口看起来像世界中的物件，例如门牌、公告牌、商店牌，而不是 UI 任务板。

星绪森林落地：

- 木屋前保留开放草地，树木只放在边界和资源区，不把主角淹没在树阵里。
- 木牌和贴纸墙靠近木屋，成为“生活记录点”。
- 桥必须位于镜头中心偏下，玩家看到桥就理解“修复后通向另一侧”。
- 主角在 1080p 截图中至少占画面高度 8%-12%，能看出黑发、紫黑衣、羽饰/贝壳和灵鱼。

### 星露谷参考方法

可学习：

- 家门口到资源点的短距离劳动闭环：出门、采集、钓鱼、回家制作/装饰。
- 玩家自由选择顺序，不用强制任务条。
- 可交互物件的反馈简单直接：物品进入背包，材料用于制作，家园逐步变好。

星绪森林落地：

- 木屋到森林、河岸、木牌、游戏机都在 5-15 秒步行范围内。
- 资源点不密集堆叠，采集后 HUD 立即显示物品数量变化。
- 木牌不说“任务”，只说“今日可换、图纸记录、小镇记录”。
- 建设后让空位变成物件，贴纸墙让小游戏成果回到家里。

### Minecraft 参考方法

可学习：

- 地形、水体、树、角色、资源都靠强几何剪影区分。
- 资源和建设的因果链明确：看到材料来源，使用材料改变世界。
- 水和地形有垂直层级，画面因此有空间深度。

星绪森林落地：

- 河流不再是一条平面色块，而是“低一层”的蓝绿河道，两侧有浅滩/河岸边缘。
- 石子、河贝、鱼影分别用形状区分：圆石、扇贝、深色鱼影。
- 桥修复前有缺口/断板，修复后是连续桥面。
- 森林少树但层次明确：近景大树 3-4 棵，背景树影 3-5 棵，采集点独立摆放。

### 星穹铁道参考方法

可学习：

- 电子入口应当一眼和生活环境不同。
- 进入后规则变化明显：主世界采集建设，小游戏变成像素贴纸收集。

星绪森林落地：

- 游戏机在自然草地里保持青绿色发光屏幕，远景光幕弱发光。
- 游戏机不是战斗入口，不做抽卡 UI，不出现大剧情压过木屋。
- 进入小游戏后镜头、背景、贴纸、出口门全部变成像素规则。

## 重新设计：WorldHub 二级画面目标

### 空间结构

```text
左后：木屋 + 贴纸墙 + 木牌
左中：开放草地，主角出生点
左前：花圃/林间路牌/自建小屋空位
中部：弯曲河道 + 半损坏桥
右中：河岸资源点，石子/河贝/鱼影
右前：游戏机空地 + 游戏机底座
右后：不可到达现代光幕
边界：少量大树组成旁友森林，不做树墙
```

### 森林标准

当前问题：树太像数组，数量偏多，缺少森林边缘和可走空地。

阶段 8B 标准：

- 主可见树木控制在 5-7 棵；其中 3 棵是大树，2-4 棵是背景小树或剪影。
- 树木不得平均排队，必须有前后错位、大小变化和开口。
- 森林边缘留出 2 个可进入缺口：一个通向树枝，一个通向花种。
- 每个采集物离树根至少 0.4-0.8 Unity 单位，避免被树冠遮住。
- 树冠颜色至少三层：暗绿主体、亮绿高光、深绿阴影；但不能把画面染成单一绿色。
- 砍伐/采集前不表现大规模森林，只表现“旁友森林边缘”，避免玩家以为要做伐木游戏。

### 河流标准

当前问题：河是蓝色长条，缺少岸线、浅滩、深浅、水面层次和桥的叙事功能。

阶段 8B 标准：

- 河道从直线改为轻微弯曲或用 3-5 段矩形/平面拼出错位岸线。
- 河水低于草地 0.08-0.18 Unity 单位，河岸用浅褐/湿土色边条表达高度差。
- 水面至少有两层：蓝绿主体 + 细窄高光条；夜晚可加弱反光。
- 河贝放在浅滩边缘，石子放在干岸，鱼影放在水中，三者不能重叠。
- 桥位于河道视觉焦点：断桥时有缺口或错位木板；修复后桥面连续并颜色更暖。

### 主角标准

当前问题：代理体有方向，但还没有参考图里那种“角色一眼记住”的强特征。

阶段 8B 标准：

- 世界中主角从方块代理升级为 2.5D 角色牌或更细的低模组合。
- 轮廓必须满足 64px 缩略图仍能看出：长黑发、紫黑衣、白羽/贝壳头饰、漂浮灵鱼。
- 三表情头像进入 HUD：安静、欢笑、激动分别用于情绪状态显示。
- 灵鱼不能只是蓝色小块，需要有“鱼身 + 尾部 + 发光边缘”的剪影。
- 主角颜色不能被森林绿或河水蓝吞掉，站在草地、河岸、木屋前都要有对比度。

### 木屋和木牌标准

- 木屋必须是主世界第一视觉锚点，不是一个棕色盒子。
- 木屋需要屋顶、门、窗、暖光、贴纸墙这 5 个识别件。
- 木牌必须有木桩、板面、小图标或色块，但不能写任务标题。
- 木屋前至少留出一块开放草地，让玩家看出这是“家门口活动区”。

### 游戏机和远景光幕标准

- 游戏机必须是自然家园里唯一的明显电子物：深灰机身、青绿色屏幕、弱发光边缘。
- 远景光幕必须更远、更高、更透明，不能抢游戏机和木屋。
- 游戏机菜单入口只显示“进入像素小游戏/旧卡带未就绪”，不做战斗、抽卡、商店。

## 交互路径重写

### 路径 A：生活采集

1. 玩家从木屋前出生，看见木牌和开放草地。
2. 玩家靠近木牌，HUD 短提示出现：`看看今日可换和图纸`。
3. 按 `E` 打开木牌，状态写入 `KnownSystems.signboard`，图纸写入 `UnlockedBlueprints`。
4. 玩家离开木牌，走到森林缺口；树枝和花种在树冠外侧可见。
5. 按 `E` 采集，`InventoryService.Add` 更新物品；HUD 背包数字立即变化。
6. 玩家去河岸，看到石子在岸上、河贝在浅滩、鱼影在水里；分别按 `E` 收集。

### 路径 B：兑换与建设

1. 玩家回到木牌，面板显示 `今日可换 / 图纸记录 / 小镇记录`。
2. 数字键 1-4 兑换成长物资；材料不足时只提示，不扣材料。
3. 玩家靠近桥或建设空位，HUD 显示对应建设提示。
4. 按 `E` 调用 `BuildService.Place`。
5. 成功：扣材料、写入 `PlacedBuildings`、空位隐藏、建设物显示。
6. 失败：材料不变、建设物不显示、HUD 短提示原因。

### 路径 D：清理空地后建设花圃

新增阶段 8B 必要行为：玩家不是直接在干净空格上凭空建设，而是先把木屋周围或森林边缘的杂草、落枝、碎石清理出来，再把空地改造成花圃或小装饰区。

参考方法：

- 动森：自然资源来自树枝、石头、杂草，材料进入 DIY/建设链；桥梁和商店等建设通过资源贡献改变岛屿。
- 星露谷：从过度生长的田地开始，清理后变成可种植、可建设的农场空间。
- Minecraft：材料来源和建设结果必须有强因果反馈。

星绪森林落地流程：

1. 玩家在木屋前或森林边缘看到 `OvergrownFlowerPlot`，外观由杂草、碎石、落枝和一圈浅色地块组成。
2. 靠近后 HUD 显示：`这片地被杂草和碎石占住了，按 E 清理。`
3. 第一次按 `E`：清理落枝，获得 `wood +1`，地块少一层落枝。
4. 第二次按 `E`：清理碎石，获得 `stone +1`，地块边界更干净。
5. 第三次按 `E`：清理杂草，获得 `flowerSeed +1`，状态写入 `ClearedWorldNodes` 或等价持久状态。
6. 清理完成后，该点变为 `FlowerBedSlot`，HUD 改为：`可以摆放花圃。`
7. 玩家满足图纸和材料后按 `E` 调用 `BuildService.Place(FlowerBed)`。
8. 成功：显示 `FlowerBed`，花丛颜色与森林花园参考图一致，但不复制具体花形和布局。
9. 失败：保持清理后的空地，不扣材料，只提示缺少材料或图纸。

实现要求：

- 新增清理状态必须能进入存档，不能只靠场景临时对象。
- 清理资源必须与物品栏联动，不能只是动画。
- 清理完成前不能建设花圃；建设完成后不能重复清理。
- 阶段 8B 最少做 1 个木屋前花圃清理点和 1 个森林边缘花圃清理点。
- 清理反馈可以先用模型层级隐藏/显示，不要求最终动画；但 HUD、资源变化和地块变化必须都有。

### 路径 C：游戏机与回家展示

1. 玩家靠近游戏机，按 `E` 发现菜单入口，状态写入 `KnownSystems.arcade`。
2. 没有旧卡带：HUD 显示 `旧卡带未就绪`。
3. 有旧卡带：按 `Enter` 调用 `MiniGameService.Start`，进入 `MiniGame01`。
4. 小游戏规则变化：不再采集材料，改为收集 3 个贴纸。
5. 收齐后出口发光；出口按 `E` 调用 `MiniGameService.Finish`。
6. 回到主世界后 `StickerWallCount +1`，贴纸墙显示新增贴纸，木牌图纸记录更新。

## 阶段 8B 实现任务

1. 重做 `WorldHubSceneBuilder` 的森林布局：减少树数量、错位摆放、加树冠层次和森林缺口。
2. 重做河流：分段河道、岸线、浅滩、湿土边、鱼影/河贝/石子分区。
3. 升级主角代理：从方块组合变为 2.5D 角色牌或更细低模组合，保留黑发、紫黑服装、头饰、灵鱼。
4. 升级木屋：屋顶、门、窗、贴纸墙、暖光和家门口活动区。
5. 升级游戏机：屏幕、按钮、底座、发现/可进入两种发光状态。
6. 新增清理空地流程：落枝/碎石/杂草 -> 获得基础材料 -> 解锁花圃建设空位 -> 建设花圃；清理状态必须持久化。
7. 增加 1080p 截图验证脚本或手动截图记录，按本文件 100 分表自评。
8. 完整跑 `tools/run-stage6-validation.ps1`，只有通过后才提交。

## 当前 review 结论

当前阶段 8A 可作为功能演示，但不能作为画面验收完成版。阶段 8B 必须优先修森林、河流和主角辨识度，再修木屋/游戏机细节。后续实现不能继续只增加功能，要先把 `WorldHub` 主世界画面推到本文件定义的 80 分以上。

## 2026-04-13 8B 实现复核
