# 星绪森林交互失败分支与边界规范

## 目标

这份文档列出交互系统的异常和边界情况。实现时必须保证失败分支不破坏状态、不误扣资源、不让玩家卡死。

## 通用规则

1. 失败分支不扣材料、不增加建设数、不写入完成状态。
2. 重复互动必须可预期：已领取、已建设、已完成时显示原因。
3. UI 打开/关闭不能阻断核心移动，除非该 UI 是明确菜单状态。
4. 存档读取失败不能创建半初始化状态。
5. 音效或视觉反馈失败不能阻断业务结果。

## 物品栏边界

| 情况 | 处理 | 必测点 |
| --- | --- | --- |
| 未知 `ItemId` | `InventoryService.Add` 返回失败 | 不写入 `Items` |
| 添加数量 <= 0 | 返回失败 | 不写入 `Items` |
| 超过单项上限 | 钳制到 `GameConstants.MaxItemStack` | 数量不超过 9999 |
| 分类页无已发现物品 | 显示“这一栏还没有发现物品” | 不显示未获得物品 |
| 开局背包 | 只显示木材、石子、花种 | 不显示河贝/鱼/旧卡带/贴纸 |

## 木牌与兑换边界

| 情况 | 处理 | 状态保护 |
| --- | --- | --- |
| 配方不存在 | 返回“兑换配方不存在” | 不扣材料 |
| 材料不足 | 返回“材料不足” | 不扣材料，不给输出 |
| 今日赠礼重复领取 | 返回“今日赠礼已经领取” | 不再增加木材 |
| 木牌首次打开 | 授予初始图纸 | 可重复打开但不重复破坏状态 |
| 快捷键超过配方数量 | 忽略 | 不报错、不改状态 |

## 建设边界

| 情况 | 处理 | 状态保护 |
| --- | --- | --- |
| 图纸未解锁 | `BuildService.CanPlace` 失败 | 不扣材料 |
| 配方不存在 | 返回失败 | 不扣材料 |
| 负数网格 | 返回“建设位置不在可放置区域” | 不写入 `PlacedBuildings` |
| 格子占用 | 返回“该位置已有建设物” | 不扣材料，不增加 `BuiltCount` |
| 材料不足 | 返回“材料不足” | 不显示建设物 |
| 修桥成功 | 写入 `PlacedBuildings`，显示修复桥 | 桥后续可通行 |
| 修桥未成功 | 桥面不开放 | 玩家仍不能过河 |

## 清理花圃边界

| 阶段 | 输入 | 成功结果 | 失败保护 |
| --- | --- | --- | --- |
| 0 | 清理落枝 | `Wood +1`，阶段变 1 | 加物品失败则阶段不变 |
| 1 | 清理碎石 | `Stone +1`，阶段变 2 | 加物品失败则阶段不变 |
| 2 | 清理杂草 | `FlowerSeed +1`，阶段变 3 | 加物品失败则阶段不变 |
| 3 | 建设花圃 | 走 `BuildService.Place(FlowerBed)` | 材料不足不回退清理状态 |

## 移动与物理边界

| 情况 | 处理 | 测试 |
| --- | --- | --- |
| 地图外 | 投影或拒绝移动 | 顶部边界、右侧岛屿上沿 |
| 未修桥进入河道 | 拒绝目标点 | 河道中心、湿土边、河道缝隙 |
| 修桥后桥面移动 | 允许通过桥通行走廊 | 从左岸到桥面、从桥面到右岸 |
| 修桥后桥外水体 | 仍拒绝 | 桥北/桥南水体 |
| 站在旧错误位置 | `ProjectOutOfRiver` 推出河道 | 河道缝隙回归 |

## 游戏机与小游戏边界

| 情况 | 处理 | 状态保护 |
| --- | --- | --- |
| 未发现游戏机 | 不能开始小游戏 | `ActiveMiniGameId` 不变 |
| 未获得旧卡带 | 菜单提示未就绪 | 不切场景 |
| 已在小游戏中再次开始 | 返回失败 | 不覆盖活动状态 |
| 贴纸不足尝试退出 | 显示“贴纸还没有收齐” | 不结算奖励 |
| 贴纸足够退出 | 结算贴纸墙和图纸进度 | 回到主世界 |

## 存档边界

| 情况 | 处理 |
| --- | --- |
| 路径为空 | `SaveService.Save` 失败 |
| 文件不存在 | `SaveService.Load` 失败，`State = null` |
| schema 无效 | 读取失败 |
| 旧存档缺少新字段 | 使用字段默认值，例如 `SignboardDailyRewardClaimed = false` |
| 字典/集合 | 通过 DTO 列表转换，避免 Unity JSON 丢状态 |

## 自动验证要求

每个修复至少跑最小测试：

```powershell
tools\run-unity-editmode-tests.ps1
```

阶段完成跑完整验证：

```powershell
tools\run-stage6-validation.ps1
```

若验证脚本因为 Unity 项目锁失败，先确认是否有编辑器窗口打开；不能把“没有生成测试 XML”当作通过。
