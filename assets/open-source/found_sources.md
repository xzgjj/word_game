# 星绪森林开源/CC0 素材候选来源

本文件只记录候选来源，不代表已经把第三方素材放入项目。正式使用前必须逐项下载、记录许可证、审查风格，再放入 `assets/open-source/` 或 `assets/processed/`。

| 来源 | 适合用途 | 当前许可认知 | 处理方式 |
| --- | --- | --- | --- |
| Kenney | UI、图标、2D/3D 占位游戏资产 | 官方支持页说明游戏资产页面为 CC0，仍需逐项确认 | 适合先找按钮、图标、低模占位 |
| Poly Haven | HDRI、纹理、3D 模型 | 官方 license 页说明资产为 CC0 | 适合地面、木材、石材、天空光照参考 |
| ambientCG | PBR 纹理 | 常见 CC0 纹理来源，需逐项确认 | 适合 Unity 材质占位 |
| OpenGameArt | 2D/3D 素材 | 许可证混合 | 只在明确 CC0 或兼容许可时使用 |

## 当前不直接下载素材的原因

- 项目还没有最终美术方向确认。
- 第三方素材需要逐项记录许可证，不能只按网站整体印象使用。
- 现阶段优先使用占位图、AI 生成提示词和可追溯来源清单。
