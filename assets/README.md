# assets

此目录用于保存《星绪森林》的素材输入、参考、生成结果和处理后资源。

- `source/`：用户提供的原始素材，不覆盖。
- `reference/`：画面对照参考图和说明。
- `generated/`：AI 生成素材。
- `open-source/`：开源或 CC0 素材。
- `processed/`：裁切、压缩、改名后的可用素材。
- `prompts/`：图片生成提示词。
- `licenses/`：素材来源、许可证和用途记录。

任何图片进入 Unity 工程前，都必须在 `licenses/asset_sources.md` 记录来源和审核状态。

素材生成优先级：

1. 先用官方/可授权参考建立方向。
2. 优先用 GPT 图片生成能力生成候选素材。
3. GPT 结果不满意时，再用 Google 图片生成。
4. 第三方开源素材必须逐项记录许可证。
5. 主角和主要场景源文件尽量 4K；低清素材只作占位并标记待优化。
