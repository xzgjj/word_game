# 星绪森林

## 游戏简介

《星绪森林》是一款轻松的小地图家园冒险游戏。玩家扮演一个会动的表情包主角，从木屋出发，查看木屋周围、旁友森林、河流和空地游戏机。玩家通过场景需求自然收集材料，修建小型设施，进入像素小游戏，收集贴纸并回到主世界。

游戏定位是“不做大地图，但做完整玩法”。第一版只做一片小森林家园，但保留后续扩展新资源、新建设物、新小游戏和新区域入口的能力。

## 当前可体验内容

- 木屋生活区：从木屋前开始，查看贴纸墙、花圃空位、工作台空位、木栅栏边界和可摆放位置。
- 自由探索：在木屋周围、旁友森林、河岸和空地之间自由查看，不使用任务列表强制引导。
- 场景采集：在森林拾取木材和表情碎片，在河岸预留石子、河贝、星屑灯芯等固定领域资源。
- 建设需求：建设物自然提示所需材料，例如木桥需要木材，花圃需要花种和石子，河岸灯需要木材和星屑灯芯。
- 过桥搭建：靠近半损坏木桥时显示材料缺口；材料足够后可修复木桥，河岸与空地连通。
- 家园设计：优先支持花圃、木栅栏、工作台、河岸灯、贴纸墙、林间路牌和游戏机底座等小型建设物。
- 时间调节：切换清晨、午后、夜晚三种小镇时间，影响光照、游戏机亮度和河岸灯提示。
- 游戏机入口：空地游戏机可进入像素模式，收集 3 个贴纸后返回主世界。
- 回收反馈：完成像素小游戏后，贴纸墙新增内容，游戏机保持点亮状态，家园记录更新。

## 主角能力

- 欢笑：大世界中加快短距离移动，像素模式中短冲刺通过缺口。
- 安静：大世界中更容易发现隐藏拾取点，像素模式中短暂漂浮通过移动平台。
- 激动：大世界中增强建设互动反馈，像素模式中高跳触发上方按钮。

## 主要功能抽象

- 探索：玩家观察场景、发现资源、查看建设缺口。
- 采集：资源来自固定领域，不靠任务奖励堆叠。
- 建设：建设物消耗材料并改变场景连通、装饰或提示。
- 时间：玩家主动切换时段，增强氛围和可见反馈。
- 小游戏：游戏机提供短关卡，产出贴纸并回到家园。
- 记录：贴纸墙和小镇记录展示玩家已经完成的行为。

## 场景

- 木屋：安全起点和贴纸墙所在位置。
- 旁友森林：提供早期资源和探索提示。
- 河流与木桥：连接起点和空地的第一道轻解谜。
- 空地游戏机：进入像素小游戏的核心入口。
- 像素小游戏：短小的贴纸收集关卡。
