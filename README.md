# 表情探索：情绪小镇

## 游戏简介

《表情探索：情绪小镇》是一款轻松的小地图冒险游戏。玩家扮演一个会动的表情包主角，从木屋出发，穿过旁友森林和河流，在空地发现一台发光游戏机。拾取游戏卡带后，主角会进入像素小游戏，收集贴纸并回到主世界。

## 当前可体验内容

- 木屋前出生。
- 旁友森林拾取木材和表情碎片。
- 河边修复木桥。
- 调节清晨、午后、夜晚三种小镇时间。
- 查看木屋周围的花圃、河岸灯和贴纸墙等建设需求。
- 空地游戏机进入像素模式。
- 像素小游戏收集 3 个贴纸。
- 完成后返回主世界，目标更新为回木屋查看贴纸墙。

## 主角能力

- 欢笑：短冲刺，用于快速通过小缺口。
- 安静：短暂漂浮，用于通过移动平台。
- 激动：高跳，用于触发高处按钮。

## 场景

- 木屋：安全起点和贴纸墙所在位置。
- 旁友森林：提供早期资源和探索提示。
- 河流与木桥：连接起点和空地的第一道轻解谜。
- 空地游戏机：进入像素小游戏的核心入口。
- 像素小游戏：短小的贴纸收集关卡。
